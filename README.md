# Personal Portfolio Website — Early Prototype

An early personal portfolio website created to practise presenting projects and building a multi-section web page.

## Overview

This project is a static portfolio prototype with Home, About, Work and Contact sections. It includes image galleries and short descriptions for sample website concepts, including a Local Business Directory, a footwear storefront concept and a restaurant website concept.

## Technologies

- HTML5
- CSS3
- JavaScript (vanilla)

The current source does not use React or Node.js. It is a front-end prototype and should not be mistaken for a production website or a full-stack application.

## Run locally

1. Clone or download the repository.
2. Open `index.html` in a modern browser.
3. Browse the page sections and project imagery.

## Project status and scope

This is an earlier portfolio experiment. The project screenshots and descriptions represent design/development concepts; they do not imply that the pictured sites are deployed, connected to live databases, or equipped with working checkout, booking or payment services.

The prototype is retained as part of a practical learning portfolio and can be refined as the projects mature.
